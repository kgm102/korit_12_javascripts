기능명: 장바구니 총 금액 계산 입력: 
상품1 가격: 10000원 상품1 수량: 2개 상품2 가격: 5000원 
상품2 수량: 1개 처리 로직: 각 상품의 가격 × 수량을 계산한다. 
두 상품의 금액을 더하여 총 금액을 구한다. 출력 예시(콘솔): "총 금액: 25000원"
내용	
let price1 = 10000;
let qty1 = 2;
let price2 = 5000;
let qty2 = 1;

let total = 0;

// 1. 상품1 금액 계산
total = price1 * qty1; (1)

// 2. 상품2 금액 계산
total = price2 * qty2; (2)

// 3. 결과 출력
console.log("총 금액: " + total + "원"); (3)

(가) - 위 (1), (2), (3) 코드 중 몇 번이 오류가 있는지 고르시오. (15점)
(나) - (가)에서 고른 코드를 수정하시오. (15점)
답)

(가) - 만약 이 코드가 순서대로 실행된다면 오류가 있는 코드는 1, 2, 3, 전부입니다.
이대로 계산한다면 토탈에는 상품 2의 값만 들어가서 5000원이 나옵니다.
최소한 토탈은 같은 변수가 아니라 예를 들어 total1 total2를 선언하여서 상품1과 2의 
금액이 분리되야합니다. 그러므로 3번도 새로 수정한 변수나 혹은 계산식을 써야해서 3번에서도 수정이 일어나야 합니다. 그러니 1, 2, 3 전부다 오류가 있습니다.

(나) - 위에서 1, 2, 3번 전부다 골랐으니 전부다 수정하겠습니다.
